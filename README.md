# ⚡ Fimro Flow

### All-in-One File Toolkit

Fimro Flow is a fast, modern, privacy-first browser toolkit that brings **55+ useful tools** for PDFs, images, documents, conversions, code, and everyday utilities into one clean interface.

> 🔒 **Your files stay on your device.**
> Fimro Flow is designed for local-first processing directly in your browser.

---

## ✨ Features

### 📄 PDF Tools

* Merge PDFs
* Split PDFs
* Compress PDFs
* Convert PDFs
* Secure PDFs

### 🖼️ Image Tools

* Compress images
* Resize images
* Edit images
* Convert images

### 📝 Document Tools

* Text processing
* Document processing
* File-based workflows

### 🔄 Converters

* Encode & decode
* Format data
* Minify code/data
* Conversion utilities

### 🛠️ Utilities

* QR Code Generator
* Password tools
* Hash generators
* Barcode generation
* Other useful utilities

---

## 🔐 Privacy First

Fimro Flow follows a **local-first architecture**.

* 🚫 No file uploads
* 🚫 No accounts required
* 🚫 No tracking
* 💻 Processing happens in your browser
* 🆓 Free to use

## Your files are processed locally instead of being sent to a remote server.

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/fimro-flow.git
```

### 2. Open the project

```bash
cd fimro-flow
```

### 3. Run

Open `index.html` in your browser.

For development, you can also use a local web server such as VS Code Live Server.
